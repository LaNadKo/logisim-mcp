# Changelog

## 1.0.0

- Russian primary README and full English documentation.
- Windows Unicode path support, including a private UTF-8 process manifest for bundled Java launchers.
- Portable offline launchers for Windows x64, Linux x64/ARM64 and macOS x64/ARM64, with pinned CPython and Temurin JDK archives.
- Bundled classic Logisim 2.7.1, native source/manual, adapter source, dependency licenses and matching OpenJDK source archive.
- Relative paths, a default `workspace/`, local `.state/`, diagnostics and generated MCP client configuration.
- Managed Logisim startup with a premain agent and cross-platform JVM attach discovery; no PowerShell process-discovery dependency on Linux/macOS.
- Preserved 54 tools and 131 resources, including full agent instructions against unrequested simplification.
- Allowlisted release packaging, per-file manifest, archive checksum, unit/protocol tests and native smoke tests.

Earlier 0.x builds were local development artifacts and are not included in the public distribution.
